# Nmap Network Scanning Assignment


##objective
To perform basic network scanning
using Nmap and identify open ports,
running services, and the operating
system.

## Installation
'''bash
sudo apt update
sudo apt install nmap
'''

## commands used
'''bash
nmap 192.168.29.235
sudo nmap -sV 192.168.29.235
sudo nmap -O 192.168.29.235
'''

##Results
-open Ports: 22(ssh), 80(http)
-ssh version: openssh 10.Op2
-http version: Apache 2.4.65
-operating system: linux

-README.md

##conclusion
Nmap successfully identified the open 
ports,service versions, and
operating system of the target
machine.
