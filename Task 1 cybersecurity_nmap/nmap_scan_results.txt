6. Security Analysis

Port 22 – SSH

SSH is commonly used for secure remote administration of Linux and Unix systems. It encrypts communication between the client and server.

Possible risks:

- Weak passwords may allow unauthorized access.
- Outdated SSH software may contain vulnerabilities.
- Exposing SSH unnecessarily increases the attack surface.

Security measures:

- Use strong authentication.
- Keep SSH software updated.
- Disable SSH access when it is not required.
- Restrict access to trusted networks where possible.

Port 80 – HTTP

HTTP is commonly used to provide websites and web applications.

Possible risks:

- HTTP does not encrypt normal web traffic.
- Sensitive information can potentially be exposed if transmitted over HTTP.
- Vulnerable web applications may be attacked through the exposed service.

Security measures:

- Use HTTPS instead of HTTP for sensitive communication.
- Keep the web server and applications updated.
- Configure appropriate firewall rules.

Port 443 – HTTPS

HTTPS provides encrypted communication between a web browser and web server using TLS.

Possible risks:

- Weak TLS configuration can reduce security.
- Outdated web-server software may contain vulnerabilities.
- Vulnerable web applications can still be attacked even when HTTPS is enabled.

Security measures:

- Keep TLS and web-server software updated.
- Disable outdated protocols and weak cryptographic settings.
- Regularly test and patch web applications.

---

7. Overall Findings

The Nmap scan identified the open ports and services running on the authorized target system. Service detection using "-sV" provided information about the software versions, while OS detection using "-O" attempted to identify the target operating system.

Open ports are not automatically vulnerabilities. However, every unnecessary exposed service increases the system's attack surface. Services should therefore be reviewed, updated, and restricted when they are not required.

---

8. Conclusion

Nmap is useful for network security assessment because it helps administrators identify exposed services and understand the attack surface of a system.

The scan should only be performed against systems that I own or have explicit permission to test. Based on the findings, unnecessary services should be disabled, required services should be properly configured, and software should be regularly patched.
